Trenutni status

Vocnjak je u ovom repozitoriju PWA/bridge i razvojna verzija. Dugoročni javni proizvodni kanal je buduća iOS/Android aplikacija nakon zasebnih owner-approved store koraka.

Zaštita podataka

Za prijenos ili čuvanje V2 podataka koristi izvoz sigurnosne kopije u Postavkama. Uvoz zamjenjuje cijelu V2 pohranu tek nakon validacije i korisničke potvrde.

Ako nešto pođe krivo

  • Izvezi V2 sigurnosnu kopiju prije većih promjena ili prije testiranja uvoza.
  • Ako uvoz javlja grešku, nemoj ručno popravljati JSON osim ako znaš točan uzrok.
  • Ako aplikacija ne radi offline, prvo je otvori jednom dok je uređaj online kako bi se bridge assets spremili.

Kontakt

Za sada se koristi postojeći privatni owner/developer kanal. Konačni javni support URL i kontakt ostaju za kasnije APP-ID-D / STORE-SUB odluke.
